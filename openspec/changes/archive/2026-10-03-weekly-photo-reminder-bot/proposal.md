# Proposal

## Why

Друзья хотят регулярно делиться фотографиями своей недели, но без напоминания это легко забыть. Нужен небольшой Telegram-бот, который будет работать в нескольких группах и отправлять настроенные напоминания по расписанию.

## What Changes

- Добавить Python Telegram-бота, которого можно добавлять в разные группы.
- Хранить отдельные настройки расписания и текста для каждой группы.
- Разрешить администраторам групп настраивать, включать, выключать и проверять напоминания командами.
- Установить значения по умолчанию: воскресенье, 20:00, `Europe/Moscow`, стандартный текст о фотографиях недели.
- Развернуть бота как постоянно работающий сервис Railway с PostgreSQL.
- Передавать токен Telegram-бота и другие чувствительные параметры через переменные окружения.

## Capabilities

### New Capabilities

- `weekly-group-reminders`: групповые еженедельные напоминания с настройками расписания, часового пояса, текста и состояния.

### Modified Capabilities

Нет существующих capabilities для изменения.

## Impact

- Новый Python-проект и зависимости Telegram Bot API.
- PostgreSQL-схема для настроек групп.
- Команды бота и проверка прав администраторов Telegram-групп.
- Планировщик отправки сообщений, устойчивый к перезапускам и повторной обработке расписания.
- Docker/Railway-конфигурация и инструкция по деплою.
